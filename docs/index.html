캠뉴런

안드로이드 폰의 좋은 카메라를 Wi-Fi로 OBS Studio에 바로. 방송용 고화질 웹캠이 됩니다.

폰 앱 받기 (체험판 APK)Android 8.0 이상 · 2027-01-31까지 프로 · 무료 PC 플러그인 설치 프로그램OBS Studio용 · Windows · 버전 0.2.5 · 무료 zip으로 직접 설치설치 프로그램이 안 될 때 체험판 설치 방법Google Play 출시 전 · APK 설치 안내

시작하기

  1. PC에 OBS Studio를 설치하고, 위의 PC 플러그인 설치 프로그램을 실행합니다. OBS가 켜져 있으면 닫을지 묻습니다.
  2. 폰에 위의 폰 앱 받기로 앱을 설치하고(설치 방법) 카메라 권한을 허용합니다. 폰과 PC는 같은 공유기에 연결돼 있어야 합니다.
  3. OBS에서 소스 추가(+) → 캠뉴런 (Android 폰 카메라). 주소 칸을 비워 두면 같은 Wi-Fi의 폰을 자동으로 찾습니다.
  4. 처음 한 번만, 폰 화면에 뜬 6자리 코드를 OBS 속성의 연결 코드 칸에 입력합니다. 다음부터는 바로 연결됩니다.

이런 점이 좋아요

선 없이 Wi-Fi로

폰을 자동으로 찾아 연결하고, 공유기가 IP를 바꿔도 다시 이어 붙습니다. USB(adb) 연결도 됩니다.

짧은 지연

폰의 하드웨어 인코더로 압축해 보내 촬영부터 OBS 화면까지 약 0.1초입니다.

폰 마이크

폰 마이크 소리를 영상과 립싱크를 맞춰 함께 보냅니다.

채팅·후원 창

치지직 위젯 주소를 넣으면 카메라를 보면서 폰 화면으로 채팅과 후원을 확인합니다.

다른 방에서 폰으로 방송 진행

폰에서 OBS 장면을 바꾸고 마이크를 켜고 끄며 방송을 시작·종료합니다. "폰으로 전환" 한 번이면 폰 장면으로 바꾸고 PC 마이크를 끕니다. PC 화면 보기(프로)로 OBS 송출 화면과 후원 소리를 폰에서 전체 화면으로 보고, 화면을 누르면 나오는 막대로 장면과 마이크를 바로 바꿉니다. 배터리가 떨어지거나 폰이 뜨거우면 폰과 OBS에 미리 알립니다. Wi-Fi가 약한 방에서는 화질을 자동으로 낮췄다 되돌리고, 끊기면 정해 둔 "잠시만요" 장면으로 바꿨다가 돌아옵니다.

폰에서 뷰티 보정

피부 보정과 밝게를 폰이 보내기 전에 직접 적용해 PC 부담이 없습니다. OBS 필터 없이 폰 설정이나 OBS 속성에서 바로 조절합니다 (프로).

양쪽에서 조절

줌, 초점, 노출, 화이트밸런스, 플래시를 폰과 OBS 어디서 바꿔도 맞춰집니다.

안전한 연결

처음 연결하는 PC는 폰의 코드를 입력해야 해서, 같은 Wi-Fi의 다른 사람이 카메라를 볼 수 없습니다.

연결이 안 될 때

OBS에서 폰을 못 찾아요
  • 폰과 PC가 같은 공유기에 연결돼 있는지 확인하세요. 게스트 Wi-Fi나 'AP 격리'가 켜진 공유기는 기기끼리 막혀 있습니다.
  • 폰에서 캠뉴런 앱이 열려 있어야 합니다. 앱 왼쪽 위의 주소(예: 192.168.0.12:9610)를 OBS 주소 칸에 직접 넣어도 됩니다.
  • 따로 설치한 보안 프로그램(백신의 방화벽 등)이 OBS의 네트워크 연결을 막고 있지 않은지 확인하세요.
설치 프로그램이 "OBS 버전이 맞지 않는다"고 해요

플러그인 0.2.5는 OBS Studio 33에 맞춰 만들었습니다. OBS가 이보다 오래됐다면 OBS를 업데이트하고, 더 새롭다면 이 페이지에서 새 플러그인이 나왔는지 확인하세요.

"Windows의 PC 보호" 창이 떠요

아직 코드 서명 인증서가 없는 설치 프로그램이라 Windows가 경고합니다. 추가 정보 → 실행을 누르면 설치됩니다. 걱정되면 zip으로 직접 설치할 수 있습니다.

플러그인을 지우고 싶어요

Windows 설정 → 앱 → 설치된 앱에서 "캠뉴런 PC 플러그인"을 제거합니다. zip으로 설치했다면 C:\ProgramData\obs-studio\plugins\obs-phonecam 폴더를 지우세요.
